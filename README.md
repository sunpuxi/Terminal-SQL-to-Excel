# SQL Console → Excel

用于将 MySQL CLI 查询结果转换为 Excel 的纯本地网页工具。

## 使用方法

1. 通过跳板机登录生产数据库并执行 SQL。
2. 复制完整的 MySQL 控制台查询结果。
3. 双击打开 `index.html`。
4. 将查询结果粘贴到输入框（粘贴后会自动解析）。
5. 检查数据预览。
6. 点击「导出 Excel」。

无需安装 Node.js、Python 或任何服务。支持 Microsoft Excel 和 WPS 可打开的 `.xlsx` 文件。

## 终端快捷打开

首次安装快捷命令：

```bash
./install-command.sh
```

安装后，在终端的任意目录输入：

```bash
sql
```

即可使用默认浏览器打开本工具。快捷命令安装在 `~/.local/bin/sql`，不会启动服务器，也不会连接数据库。

## 支持范围

- MySQL CLI 默认表格输出格式
- 中文、`NULL` 和空字段
- 导出前可勾选需要写入 Excel 的字段
- 最多预览前 100 行，Excel 导出全部数据
- 自动列宽、表头样式和筛选
- 10,000 行以内的日常查询结果

## 数据安全

所有数据均在浏览器本地内存中处理：

- 不连接数据库
- 不上传数据
- 不发送网络请求
- 刷新或关闭页面后数据即消失

`libs/xlsx.full.min.js` 是随项目附带的本地依赖，页面不依赖 CDN，断网也可使用。
